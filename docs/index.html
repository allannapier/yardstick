ys -- measurement rig

Measure your coding agent, not just its vibes.

yardstick sits between a coding agent (Claude Code, opencode, ...) and the LLM API as a LiteLLM proxy, recording every request and response into a local SQLite database -- so you can compare arms of an experiment (same task, different model or harness config) on cost, tokens, turns, tool-call efficiency, and task success.

It measures: cost and billable tokens, turns, cache-read ratio, tool-call counts and errors, redundant tool calls, compaction events, context high-water mark, wall-clock time, and task success.

How it works

The measurement loop is five commands, run once per arm of an experiment.

The same loop also runs entirely from the browser via ys web up -- see tutorial 1 for both on-ramps side by side, or jump straight to tutorial 5.

  1. Proxy up

    ys proxy up --exp experiments/example.yaml generates a LiteLLM proxy config from your experiment YAML(s) and starts the proxy that will record every request.

  2. Harness point

    ys harness point claude-code repoints the agent's config (e.g. Claude Code's ~/.claude/settings.json) at that proxy, backing up the original first.

  3. ys start

    ys start --exp ... --arm ... marks a run active; you then drive the agent through its task as normal.

  4. ys end

    ys end finishes the run, runs the arm's success_check, and prints headline metrics.

  5. Compare / report

    ys compare and ys report aggregate recorded runs per arm into a table or a self-contained HTML report.

Quick start

Requires Python >= 3.10. Installs the ys CLI with litellm[proxy], FastAPI/uvicorn (dashboard), and Pydantic.

bash 
pip install -e .

ys init                                    # create ~/.yardstick and the db

export LITELLM_MASTER_KEY=sk-...           # proxy auth key you choose
ys proxy up --exp experiments/example.yaml # start the measurement proxy

ys harness point claude-code               # point Claude Code at the proxy
ys start --exp experiments/example.yaml --arm arm-a

# ... drive the agent through the task ...

ys end                                     # score + print headline metrics
ys harness reset claude-code               # restore the agent's real config
ys proxy down
